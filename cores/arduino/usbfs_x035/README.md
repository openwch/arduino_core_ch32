The CH32X035 USB CDC device code is adapted from WCH's
[SimulateCDC example](https://github.com/openwch/ch32x035/tree/main/EVT/EXAM/USB/USBFS/DEVICE/SimulateCDC).
The WCH source notices and restrictions apply. The WCH example's USB
descriptor identifiers are retained. The UART bridge has been replaced with
CDC state for the Arduino `Serial` interface.
